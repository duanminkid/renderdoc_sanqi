# 核心代码规范

## 热路径优化
- 高频调用的函数避免不必要的分配
- 使用对象池或预分配缓冲区
- 缓存重复计算的结果

## 线程安全
- 共享可变状态必须有同步机制
- 优先使用不可变数据结构
- 并发访问的数据结构必须文档化其线程安全性

## API 稳定性
- 公开接口向后兼容
- 废弃接口标记 @deprecated 并给出替代方案
- 接口变更需更新所有调用方和测试

## 错误处理
- 不吞掉异常（除非有明确理由并注释）
- 错误信息包含足够的调试上下文
- 区分可恢复和不可恢复错误

## 依赖方向
- 核心模块不依赖应用层模块
- 抽象定义在核心层，实现在外层
- 避免循环依赖
